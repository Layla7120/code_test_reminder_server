# 용어집

이 저장소의 문서·주석·ADR 이 같은 뜻으로 쓰는 말. **한 번 여기 적힌 말은 다른 뜻으로 쓰지 않는다.**
왜 그렇게 정했는지는 링크된 ADR 에 있다.

## 데이터

| 말 | 뜻 |
|---|---|
| **진실 원천** | 어떤 사실을 처음 기록한 곳. `commits` 는 커밋 수의, `participate` 는 그룹 인원의 원천 |
| **파생 사본** | 원천에서 계산해 따로 저장한 값 (`user_monthly_score.score`, `groups.member_counter`). **여럿이면 반드시 어긋난다** |
| **드리프트** | 파생 사본이 원천과 어긋난 상태. 위험한 건 값이 틀려서가 아니라 **틀렸다는 사실이 안 보여서**다 |
| **대사** | 드리프트를 찾아 알리거나 고치는 작업. 자동 교정 대사는 위험하다 → [0006](adr/0006-member-counter-대사를-두지-않는다.md) |
| **절대값 재계산 / 증분** | `score = COUNT(*)` 대 `score += n`. 증분은 한 번 틀리면 복구가 안 된다 |
| **독립적 제2진술** | 사람이 **의도**를 따로 적은 것. 파생 사본과 달리 **둘이어야** 의미가 있다 — 어긋남 자체가 정보다 → [0008](adr/0008-검증을-앵커와-게이트로-한다.md) |

> 진실 원천이 하나여야 한다는 건 파생 사본에 대한 규칙이지, 의도를 진술하는 곳에 대한 규칙이
> 아니다. 이 구별을 놓치면 테스트를 "중복"이라며 지운다.

## 삭제

| 말 | 뜻 |
|---|---|
| **소프트 / 물리 삭제** | 플래그로 표시하고 행을 남기는가, 실제로 지우는가. **이 저장소는 물리 삭제뿐이다** → [0001](adr/0001-사용자-삭제를-물리-삭제로-단일화한다.md) |
| **CASCADE / RESTRICT** | 부모가 지워질 때 자식을 같이 지우는가, 막는가. **CASCADE 는 그 행이 다른 파생값의 원천이 아닐 때만 안전하다** → [0002](adr/0002-cascade-는-파생값의-원천이-아닐-때만-건다.md) |

> MySQL 은 `ON DELETE` 절이 없는 FK 를 `information_schema` 에 `RESTRICT` 가 아니라
> **`NO ACTION`** 으로 보고한다. InnoDB 에서 동작은 같다.

## 검증

| 말 | 뜻 |
|---|---|
| **앵커** | 기계가 참·거짓을 판정할 수 있는 사실 하나. "잘 되어 있다"가 아니라 `DELETE_RULE = 'CASCADE'` |
| **게이트** | 앵커가 거짓이면 **빌드를 깨는** 장치. 사람이 읽고 판단하지 않는다 → [0008](adr/0008-검증을-앵커와-게이트로-한다.md) |
| **고의 파손** | 테스트를 낸 뒤 본문을 일부러 망가뜨려 빨간불을 확인하는 것. 지웠을 때 안 깨지는 코드는 검증되고 있지 않다 |
| **부채 명세서** | `endpoint-allowlist.txt` 처럼 "아직 못 한 것"을 적는 파일. **예외 처리가 아니다** — 목록에 없으면 빌드가 깨지는 게 목적이다 |
| **포트 / 어댑터** | 포트는 앱이 소유한 인터페이스, 어댑터는 그 구현. `GithubClientPort` 가 포트다 |

> **포트의 위치가 곧 테스트 경계다.** 테스트 더블이 포트를 구현하므로 포트보다 아래에 있는
> 코드는 그 더블로 검증할 수 없다 → [0004](adr/0004-페이지네이션-루프를-포트-아래-두고-http-를-가짜로-만든다.md)

**현재 도는 게이트 4개** — `verifyEndpointCoverage` · `SchemaContractTest` ·
`DocReferenceGateTest` · `DeadCodeGateTest`.

## 시간

**KST 판정 / UTC 저장** — `commits.commit_date` 는 GitHub 이 준 UTC 를 그대로 담고,
"그날"·"이번 달" 판정은 KST 로 한다. 변환 지점은 `global/ServiceZone` 하나뿐이고,
*"이 컬럼은 UTC 다"* 는 `DATETIME` 이 타임존을 갖지 않으므로 **코드로만 유지되는 약속**이다.

## 문서

**세 층, 시제로 나뉜다** — ADR·README·AGENTS 는 **현재**, 진행 중인 계획은 **미래**,
`docs/기록.md` 와 `docs/archive/` 는 **과거**. 과거 층은 그 시점의 사실이라 지금 코드와
어긋나는 게 정상이고 게이트 대상이 아니다 → [0007](adr/0007-문서를-시제로-세-층으로-나눈다.md)

**ADR** — 결정 하나당 한 파일. **무엇을 검토하고 버렸는지**와 **잃는 것**을 적는다.
